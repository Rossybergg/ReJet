ReJet {version}
Jet Set Radio Future on Windows, from your own disc.

Not affiliated with Sega, Smilebit or Microsoft. No game data is included: you need your own
disc image of the PAL Xbox release of Jet Set Radio Future.


FIRST START

1. Unzip this folder anywhere you can write to (for example Documents\ReJet).
2. Run ReJet.exe.
3. Choose your disc image (.iso) or a folder you already extracted it to. ReJet checks it is
   the supported PAL release and copies the game files into a "Game" folder here (about 2.5 GB).
4. The game starts. Next time, ReJet.exe starts the game straight away.


PLAYING

  ReJet menu (pause, settings, bug reports)   F1, or Back + Start on a controller
  Move                                         left stick / W A S D
  Jump                                         A / Space or Z
  Boost, spray                                 B / X
  X / Y                                        X / Y / C / V
  Triggers                                     LT / RT / Q / E
  Start / Back                                 Start / Back / Enter / Backspace

Settings (resolution, widescreen, full screen, filtering, volume) are in the ReJet menu and are
remembered between sessions (rejet.ini, next to ReJet.exe). Saves are kept in
%LOCALAPPDATA%\rejet.


REPORTING BUGS

This is an alpha: please report what you find.

1. When something goes wrong, open the ReJet menu right there and choose "Report a bug": pick
   what went wrong and type a short note. ReJet saves a capture of that moment in the
   "captures" folder here. (F11 makes a capture without the menu; F12 takes a screenshot;
   F10 writes a marker in the log.)
2. Send the capture folder (zipped) and loader.log from this folder. If the game crashed,
   loader.log is enough. Older logs are in the "logs" folder.

Every log and capture says which ReJet version made it; the version is also shown in the
ReJet menu (bottom right).
